# Chembarathi Image Library

This folder is the growing library of Chembarathi source images. Add every supplied image here so it is available for future content. Do not choose or remove images based on a particular post.

## Add new images

1. Copy each supplied image into this folder. Leave the original untouched and keep the library copy full-size and uncropped. Do not resize, retouch, or otherwise change the image content.
2. Give the library copy a short, descriptive filename based on its visible content or supplied context. Use lowercase words separated by underscores, for example `garden_view.jpg`. Do not guess details that are not known.
3. Add one entry for the image to [image_library.md](image_library.md), including the original filename, exact source path, new library path, and a short description of what is visible. Include visible subject details when possible: people and their apparent gender presentation, a broad age range only when clear, animals, and whether the image is a photograph, illustration, or animation. Describe only what is visible; mark uncertain details as unknown rather than guessing.

Keep post-specific crops, text, and design treatments in separate working files or layers. Never crop or edit the original or the library copy.
